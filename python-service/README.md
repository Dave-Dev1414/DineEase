\# DineEase Python Service

A separate Python API service for future DineEase AI and analytics features.

\## Requirements

\- Python 3.13+

\- A virtual environment


\## Setup on Windows CMD

From the `python-service` directory:

```cmd

python -m venv .venv

.venv\\Scripts\\activate

python -m pip install -r requirements-dev.txt

copy .env.example .env
